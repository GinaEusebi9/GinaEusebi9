### 🏥 Implementation work · Public healthcare

Real-world rollouts for the Municipality of Córdoba's health network.

#### 🧾 Etendo ERP rollout across three health services
Functional implementation of **Etendo ERP** in the **Municipal Dental Service**, **SEMM 107** (emergency medical service) and the **Pharmacy Warehouse** of the Primary Health Care Directorate.  
`Requirements gathering` `Process modeling` `ERP configuration` `Testing` `User training` `Go-live support`

#### 💊 Dispensar: medication stock in municipal health centers
Rollout of **Dispensar**, the system that manages medication stock and dispensing across municipal health centers. I adapted it to each center's workflow, trained the teams and supported them after launch.  
`Implementation` `Stock processes` `Training` `Functional support`

#### 🤖 Permission automation in ehCOS
**Selenium** automation for setting up user permissions and schedule (agenda) permissions in **ehCOS**, the hospital information system. It replaces slow, error-prone manual configuration with repeatable scripts.  
`Selenium` `Test automation` `Access management` `Process improvement`

> 🔒 These projects run on private, institutional systems, so their code and data aren't public. I'm happy to walk through the process, decisions and results in an interview.
